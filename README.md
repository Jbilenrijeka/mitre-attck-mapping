# MITRE ATT&CK Behavior Mapping

## Objective
Demonstrate how to map observed behavior to ATT&CK concepts without claiming an attacker identity or technique unsupported by evidence.

## Files
- `observations.csv` — simulated observations.
- `mapping.md` — cautious mapping rationale.

## Note
Technique IDs and descriptions can evolve. Check the official MITRE ATT&CK knowledge base when using this in a real investigation.
